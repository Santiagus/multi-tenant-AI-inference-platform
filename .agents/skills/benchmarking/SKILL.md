# Benchmarking

Every benchmark records:
- hardware/environment;
- software/model version;
- workload;
- concurrency;
- duration/sample count;
- metric definition;
- warm/cold state;
- result.

Never manufacture benchmark results. Prefer reproducible scripts and committed methodology over screenshots alone.
