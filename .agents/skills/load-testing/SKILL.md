# Load Testing

Default tool: Locust. Use realistic arrival-rate/load profiles.

Measure: throughput, queue wait, service latency, P50/P95/P99, errors, saturation.

Use Little's Law where appropriate for capacity reasoning. Never report peak throughput without workload and saturation conditions.
